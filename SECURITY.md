## Reporting a Vulnerability

The BuildSite team takes security seriously. If you discover a security vulnerability in this project:

1. **Do not create a public GitHub issue.**
2. Send a detailed report via email to **security@buildsite.dev**.
3. Please include:
   - Description of the vulnerability and potential impact.
   - Exact steps or minimal proof-of-concept to reproduce the issue.
   - Proposed fix or remediation, if available.

We will acknowledge receipt within 48 hours and work with you to coordinate a responsible disclosure and patch release.
