# 自动更新与共享缓存验证

以下为v0.1.0的自动刷新和并发验证摘要。

| 检查 | 观察结果 |
|---|---|
| 页面自动读取 | 两个独立页面均产生自动健康检查，观察到行情自动读取及缓存复用 |
| 数值更新 | 本地隔离环境回放14:59至15:00的缓存，两页数值均自动更新；一次行情请求间隔为60.271秒 |
| 并发读取 | 20个并发客户端各读3次，共60次HTTP请求均成功，返回同一采集时间的缓存 |
| 网页出站 | 同版本隔离网关记录的供应商出站调用为0 |
| 后台分工 | 并发访问前后行情缓存及后台采集记录保持一致 |
| 凭据配置 | 网页服务读取缓存，FtShare Key配置在后台采集端 |

页面盘中按60秒、非交易时段按300秒读取；新页面首轮为60秒。页面自动读取在收盘后观察，数值变化通过历史缓存回放验证；并发结果与出站计数分别来自站点响应和同版本隔离网关。

复验方法见[验证指南](verification.md)，配置见[云端部署](cloud-scheduled-update.md)。
