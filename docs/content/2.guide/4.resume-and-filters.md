## Continue

Resume is on by default. The database remembers the list URL for each combination of sort and categories.

```bash
avherald-scraper --limit 50
avherald-scraper --limit 50
```

The second command does not count ids that are already stored. It asks for 50 headlines it has not kept yet.

`--no-resume` always starts at the first page but still skips stored ids. `--fresh` deletes the saved position for this filter and starts at the first page.

## Filter

Empty categories means every icon. Otherwise name the ones you want:

```bash
avherald-scraper -c crash -c accident --sort occurrence
```

Sort `update` follows the site's "latest updates" order. Sort `occurrence` follows occurrence date. The first URL is the site root only when sort is `update` and no category is selected. Other combinations set the site's `opt` value: occurrence `1`, crash `256`, accident `512`, incident `1024`, news `2048`, report `4096`.

## Stop early

`--pages 2` stops after two list pages even if the limit is not filled. `--limit` stops after that many new headlines, even in the middle of a page. If the page still has headlines you have not stored, the next run stays on that page.

## Check a run

Each run writes a page log, by default `data/avherald.pages.json` beside the database. Open it after a run to see which pages came back and which one stopped the crawl.

```json
{
  "run_started_at": "2026-11-14T09:12:44+00:00",
  "pages": [
    {"url": "https://avherald.com/", "status": "ok", "attempts": 1, "error": null},
    {"url": "https://avherald.com/h?list=&opt=0&offset=...", "status": "blocked", "attempts": 2, "error": "avherald.com blocked this IP"}
  ],
  "resume_url": "https://avherald.com/h?list=&opt=0&offset=..."
}
```

`resume_url` is the page the next run opens. When a page is `blocked` or `failed`, the rows from earlier pages are still written, and the bookmark points at the failed page, so the next run retries it rather than skipping ahead. Fix the proxy and run the same command again.

`--dry-run` writes this file too. Use `--pages-log` or `pages_log` in the `crawl` section of `config.ini` to put it somewhere else; the flag wins.
