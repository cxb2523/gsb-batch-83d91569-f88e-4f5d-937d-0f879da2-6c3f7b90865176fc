A direct connection is the default. Set proxies only when the site answers with its unauthorized-access page, or when you already reach the site through a proxy.

## In the command

```bash
avherald-scraper --proxy http://127.0.0.1:8080 --proxy http://127.0.0.1:8081
```

Commas work too: `--proxy http://127.0.0.1:8080,http://127.0.0.1:8081`.

## In config.ini

```ini
[network]
proxy = http://127.0.0.1:8080, http://127.0.0.1:8081
```

A command-line `--proxy` replaces that list. It does not append to it.

## What a failure does

A ban page, a connection error, a timeout, or an HTTP error drops the current proxy and retries the same list URL on the next one. The pause between pages is not repeated for that retry. When the last proxy fails, the run stops and exits with status `1`.

The page log records this. A retried URL has one entry, not one per proxy; `attempts` is the number of requests that URL took. The entry is `blocked` when every proxy served the ban page and `failed` when an HTTP or network error outlived the last proxy. `resume_url` points at that page, so fixing the proxy and running again continues there.

The progress summary says how many proxies are configured. It does not print the URLs, because a URL can contain a password.
