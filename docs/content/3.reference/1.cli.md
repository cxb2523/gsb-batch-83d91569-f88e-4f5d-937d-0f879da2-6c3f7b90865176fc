The command is `avherald-scraper`. `python -m avherald_scraper` calls the same function.

## Exit codes

| Code | Meaning |
| --- | --- |
| 0 | The run finished |
| 1 | A request failed, every proxy was blocked, or the page log could not be written |
| 2 | The configuration is invalid |

A blocked or failed page does not discard the run. The headlines already stored are kept and written, and the page log says where the walk stopped.

## Progress

On a terminal, stderr shows a bar from the start of the crawl, including the wait for the first page. The bar is `kept/limit`. `skipped` appears when some ids were already stored. `--quiet` disables it. Pipes do not get the live bar. The summary on stdout stays short:

```text
8 kept   8 new   3 skipped
data/avherald.sqlite   140 stored
pages: data/avherald.pages.json
```

## Page log

Every run writes one JSON file. It records each list URL in request order, whether it came back (`ok`), was refused by the site (`blocked`), or failed for another reason (`failed`), and how many requests that URL took. A proxy retry adds to `attempts` but stays one page. Reading it shows which page stopped the run and where the next run continues.

The default path is the database folder and stem, with `.pages.json` instead of `.sqlite`. `--pages-log PATH` or `pages_log` in the `crawl` section of `config.ini` moves it; the flag wins. The format is described under [Database](/reference/database).

## Flags

| Flag | Default |
| --- | --- |
| `-n`, `--limit` | 10 in the shipped `config.ini`, otherwise 50 |
| `-p`, `--pages` | no page cap |
| `-c`, `--category` | all |
| `--sort` | `update` |
| `-o`, `--db` | `data/avherald.sqlite` |
| `--format` | `sqlite` |
| `-d`, `--delay` | 3 seconds |
| `--proxy` | direct |
| `--timeout` | 20 seconds |
| `--user-agent` | a string that names this tool |
| `--pages-log` | `<database stem>.pages.json` beside the database |
| `--dry-run` | off |
| `--resume` / `--no-resume` | on |
| `--fresh` | off |
| `--config` | `./config.ini` when that file exists |
| `--start-url` | built from sort and category |
| `--show-config` | off |
| `-v`, `--verbose` | off. Lists the kept headlines |
| `-q`, `--quiet` | off |
