# Progression & Evolution Guide

Every verified contribution to GitHub advances your property's construction state. BuildSite implements a non-punitive, multi-tiered progression engine supporting continuous growth from your first commit to decades of open-source work.

---

## Micro-Evolution Mechanics

Progression is not a long desert between distant milestones. **Every single commit advances your property**:
- Progress ratio percentage in the HUD updates continuously.
- Micro-details (e.g. trenching, rebar, individual column pours, paver laying, shrub planting) unlock at specific counts within each bracket.
- State file keeps a verifiable audit trail of all architectural unlocks.

---

## Long-Term Continuous Progression (1,501+ Contributions)

BuildSite does not terminate once the main residence is completed.
For developers with thousands of contributions, the estate enters the **Prestige Master Estate** phase:
- Unlocks in 500-contribution continuous prestige tiers.
- The property expands with secondary amenities, private grove landscaping, and grand architectural estate lighting.
- Progression remains endless and rewarding over multiple years.

---

## Non-Regression Guarantee

If GitHub API reports a temporary drop in visible contribution counts (due to permission adjustments, API latency, or private contribution toggles), BuildSite's **non-regression guard** preserves your previously earned construction state when `preserve_unlocks: true` is configured.
Your house will never be demolished because of a temporary GitHub API discrepancy.
