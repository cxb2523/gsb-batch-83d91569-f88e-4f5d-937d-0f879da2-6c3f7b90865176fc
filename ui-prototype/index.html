Dual WAN

Use a second internet connection for automatic backup, or share the load across both.

Mode?Failover: use the backup only when the primary goes down. Load balance: use both at once. Off: single connection as normal.
Primary?The connection used first. Health is checked by pinging 8.8.8.8 and 1.1.1.1.
Backup?Used only when the primary fails (failover) or shares traffic (load balance).
Advanced details
Writes a clean mwan3 config in /etc/config/mwan3: two tracked interfaces (ping health check), two members (equal metric = balance, stepped = failover), a policy and a catch-all rule.
Advanced Settings

UPnP

Let games and apps open the ports they need automatically — no manual port forwarding.

Allow automatic port opening?Lets consoles and apps request inbound ports on demand. Convenient, but any app on your network can open a port — leave off if you don't need it.
Secure mode?A device may only open ports to itself, not redirect traffic to other devices. Recommended — keep this on.
Advanced details
Toggles miniupnpd-nftables (UPnP IGD + NAT-PMP) via /etc/config/upnpd, listening on lan and mapping to wan. This is the modern replacement for old-style “port triggering,” which current OpenWRT (nftables) doesn't support — for a fixed service, use Port Forwarding.
